# Menu packaging and delivery package — Design Spec

Date: 2026-09-18  
Status: Approved for user review  
Version: v1

ขยาย `2026-09-08-menu-cost-calculator-design.md` และหน้าขายออกใน `2026-09-09-buy-sell-design.md`

## Problem

ต้นทุนเมนูคิดแค่สูตรน้ำ ยังไม่นับแก้ว ถุง ของเมนูนั้น และยังไม่มีชุดแพ็กส่งกลางที่เมนูน้ำหยิบไปใช้ เลยเทียบกำไรหน้าร้านกับเดลิเวอรีไม่ได้ และตั้งราคาจากเป้ากำไร % หรือบาทไม่ได้

## Goals

- สร้างเมนูได้สองแบบ ติ๊กได้ว่า **นี่คือ delivery package ไม่ใช่เมนูน้ำ** เพื่อให้ไปอยู่ในรายการชุดแพ็กส่ง
- ชุดแพ็กส่งเลือกของจากคลัง ใส่จำนวน ต้นทุนตามของที่ซื้อ มีได้หลายชุด
- เมนูน้ำแต่ละบรรทัดติ๊กได้ว่า **ค่า Package ไม่ใช่เมนูน้ำ**
- เมนูน้ำมีช่อง **เลือกชุดแพ็กส่ง** เป็นรายการเลือกหนึ่งชุด จากชุดแพ็กส่งที่มีอยู่ ไม่ใช่ติ๊ก เพราะมีหลายตัว **ไม่บังคับ** ถ้ามีเดลิเวอรีค่อยเลือกว่าเป็นแพ็กเกจใด เว้นว่างได้ถ้าเมนูนั้นไม่คิดเดลิเวอรี
- หน้าเมนูโชว์ต้นทุน ราคา กำไรบาท กำไร% ของหน้าร้านกับเดลิเวอรีคู่กันเมื่อมีชุดแพ็กส่ง
- สองราคาขาย: หน้าร้าน และเดลิเวอรี
- ตั้งเป้ากำไรเป็น % หรือบาท แล้วคำราคาขายได้ และยังกรอกราคาเองแล้วดูกำไรได้
- กำไร% = กำไรสุทธิหลังหัก GP ÷ ราคาขาย
- ขายออกเลือกหน้าร้านหรือเดลิเวอรี ตัดของตามโหมดนั้น
- ชุดแพ็กส่งไม่โชว์ในหน้าขายออก

## Non-goals

- ไม่มีคลังแพ็กแยกจากวัตถุดิบ
- ไม่กรอกค่าแพ็กเป็นบาทโดยไม่ผูกของในคลัง
- ไม่เลือกแพ็กส่งหลายชุดต่อเมนูน้ำ
- ไม่ให้ชุดแพ็กส่งชี้ชุดแพ็กส่งอื่น (ห้ามซ้อน)
- ไม่มีค่าส่งที่ร้านจ่ายเป็นก้อนแยกจากของแพ็ก
- ไม่เปลี่ยนสูตรเฉลี่ยต้นทุนวัตถุดิบ

## Data model

ไฟล์ใหม่เท่านั้น ห้ามแก้ migration ที่รันไปแล้ว

`products`

- `is_delivery_package boolean not null default false`
- `delivery_package_id uuid null references products(id)`
- `selling_price_delivery numeric null` ตรวจมากกว่า 0 ถ้ามีค่า เหมือนราคาขายหน้าร้าน

กฎ

- เมนูน้ำ: `is_delivery_package = false` ชี้ `delivery_package_id` ได้เฉพาะแถวที่ `is_delivery_package = true` และคนละ id
- ชุดแพ็กส่ง: `is_delivery_package = true` แล้ว `delivery_package_id` ต้องเป็น null ไม่ใช้ `selling_price` / `selling_price_delivery` ตอนขาย
- ลบชุดแพ็กส่งไม่ได้ถ้ายังมีเมนูน้ำชี้มา
- เมนูเดิมทั้งหมดเป็นเมนูน้ำ ไม่มีชุดแพ็กส่ง

`product_ingredients`

- `is_packaging boolean not null default false`
- บรรทัดเดิมเป็น `false` (เมนูน้ำ)
- บนชุดแพ็กส่ง ติ๊กนี้ไม่มีผลต่อต้นทุน ทุกบรรทัดในชุดนับรวมในต้นทุนชุดนั้นอยู่แล้ว

`stock_sales`

- `fulfillment text not null default 'dine_in'` ค่าที่อนุญาต `dine_in` | `delivery`

## Calculation

ต้นทุนชุดแพ็กส่ง = ผลรวมต้นทุนบรรทัดของเมนูนั้น (ของคลัง × ปริมาณ)  
ต้นทุนหน้าร้านของเมนูน้ำ = ผลรวมต้นทุนทุกบรรทัดของเมนูน้ำนั้น (ทั้งที่ติ๊ก Package และที่ไม่ติ๊ก)  
ต้นทุนเดลิเวอรี = ต้นทุนหน้าร้าน + ต้นทุนชุดแพ็กส่งที่เลือก  
ถ้าไม่มี `delivery_package_id` ไม่มีต้นทุนเดลิเวอรี ไม่มีคอลัมน์เดลิเวอรี

```
channelFee = sellingPrice × (feePercent / 100)
netReceived = sellingPrice − channelFee
netProfit = netReceived − costOfThatMode
profitPercent = netProfit / sellingPrice
```

คำราคาจากเป้ากำไรสุทธิหลัง GP ของช่องทางที่เลือก

เป้าเป็นเศษส่วน `m` เช่น 20% → `0.20` GP เป็นเศษส่วน `g` เช่น 32% → `0.32`

```
sellingFromPercent = cost / (1 − g − m)
sellingFromBaht = (cost + targetBaht) / (1 − g)
```

ถ้า `1 − g − m ≤ 0` หรือ `1 − g ≤ 0` หรือเป้า % / บาทไม่มากกว่า 0 ไม่คำราคา ข้อความไทยว่าตั้งสูงไปหรือกรอกไม่ถูก  
ราคาแนะนำใส่ลงช่องราคาขายของคอลัมน์นั้นได้ ยังแก้เองได้

ตัวอย่าง: ต้นทุน 50 GP 32% อยากกำไรสุทธิ 20% → ราคา = 50 / 0.48 ≈ 104.17  
อยากกำไร 15 บาท → ราคา = 65 / 0.68 ≈ 95.59

## UI

หน้า `/products` ฟอร์มเพิ่ม/แก้

- ติ๊ก **นี่คือ delivery package ไม่ใช่เมนูน้ำ**
- รายการต้นทุนรายการเดียว เลือกของจากคลัง ใส่จำนวน ติ๊ก **ค่า Package ไม่ใช่เมนูน้ำ** ได้ต่อบรรทัด
- ถ้าเป็นเมนูน้ำ: ช่องเลือก **ชุดแพ็กส่ง** เป็น dropdown รายชื่อชุดแพ็กส่งทั้งหมด (เช่น Package Delivery Matcha Latte) เลือกได้หนึ่งชุดหรือเว้นว่าง **ไม่บังคับ** ถ้าจะคิดเดลิเวอรีค่อยเลือกว่าใช้แพ็กเกจใด
- ถ้าเป็นชุดแพ็กส่ง: ไม่มีช่องชุดแพ็กส่ง ไม่มีสองราคาขาย ไม่มีเป้ากำไรเพื่อขาย โชว์ต้นทุนชุดนั้นอย่างเดียว
- เมนูน้ำที่มีชุดแพ็กส่ง: สองคอลัมน์ หน้าร้าน / เดลิเวอรี แต่ละคอลัมน์มีต้นทุน เป้ากำไร (% หรือบาท) เลือกช่องทางเพื่อคำราคา ช่องราคาขาย ตาราง GP / ได้เงินจริง / กำไรบาท / กำไร%
- เมนูน้ำที่ไม่มีชุดแพ็กส่ง: คอลัมน์หน้าร้านอย่างเดียว

ตารางรายการเมนู: ชุดแพ็กส่งติดป้ายว่าเป็นแพ็กส่ง โชว์ต้นทุน ไม่โชว์ราคาขายลูกค้า  
เมนูน้ำโชว์ต้นทุนและราคาหน้าร้าน และถ้ามีชุดแพ็กส่งโชว์ต้นทุนและราคาเดลิเวอรีด้วย

หน้า `/sales`

- เลือกได้เฉพาะเมนูน้ำ
- เลือก **หน้าร้าน** หรือ **เดลิเวอรี**
- ไม่มีชุดแพ็กส่งแล้วเลือกเดลิเวอรีไม่ได้
- เดลิเวอรีแต่ยังไม่มีราคาขายส่ง ขายไม่ได้
- หน้าร้านใช้ `selling_price` ตัดทุกบรรทัดของเมนูน้ำ
- เดลิเวอรีใช้ `selling_price_delivery` ตัดทุกบรรทัดของเมนูน้ำบวกทุกบรรทัดของชุดแพ็กส่ง
- ของไม่พอในโหมดนั้น ขายไม่ได้ ข้อความขาดของภาษาไทยแบบเดิม

## Error handling

| กรณี | ข้อความ |
|---|---|
| เมนูน้ำไม่มีบรรทัดต้นทุน | เหมือนเดิม ต้องมีวัตถุดิบในสูตร |
| ชุดแพ็กส่งไม่มีบรรทัด | ใส่ของในชุดแพ็กส่ง |
| ชี้ชุดแพ็กส่งที่ไม่ใช่ delivery package | เลือกชุดแพ็กส่งจากรายการ |
| เป้ากำไรสูงเกินจนหารไม่ได้ | ตั้งเป้ากำไรต่ำกว่านี้ เพราะบวก GP แล้วเต็มหรือเกิน 100% |
| ลบชุดแพ็กส่งที่เมนูน้ำยังใช้อยู่ | ลบไม่ได้ เพราะมีเมนูใช้อยู่ |
| ขายเดลิเวอรีของไม่พอ | ข้อความขาดของรายการที่ขาด รวมของในชุดแพ็กส่ง |

## Testing

1. สร้างชุด «Package Delivery Matcha Latte» ติ๊ก delivery package ต้นทุนตามของในคลัง หน้าขายออกไม่มีเมนูนี้ในรายการเลือก
2. เมนูน้ำถุง 1 ใบ อีกเมนูถุง 2 ใบ ทั้งคู่ติ๊กค่า Package ต้นทุนแพ็กต่างกัน
3. เมนูน้ำเลือกชุดแพ็กส่ง หน้าเมนูโชว์สองคอลัมน์ ต้นทุนเดลิเวอรี = หน้าร้าน + ต้นทุนชุด
4. ไม่เลือกชุดแพ็กส่ง โชว์คอลัมน์หน้าร้านอย่างเดียว
5. GP 32% ต้นทุน 50 เป้า 20% ได้ราคา 104.17 เป้า 15 บาทได้ราคา 95.59
6. ขายหน้าร้านไม่ตัดของในชุดแพ็กส่ง ขายเดลิเวอรีตัดทั้งเมนูน้ำและชุดแพ็กส่ง
7. ของในชุดแพ็กส่งไม่พอ ขายเดลิเวอรีไม่ได้ ขายหน้าร้านได้ถ้าของหน้าร้านพอ
8. ลบชุดแพ็กส่งขณะมีเมนูน้ำชี้มาไม่ได้
